# C · 画廊式黑盒作品集（DARK PORTFOLIO）

> 作品，成为视觉中心。整套 deck 是一间黑盒画廊：作品挂在近黑墙面上、带细框留白，旁边是展签式小字；超大极细 Didot 编号像墙上的水印。
> 样例：「器物与空间 · 作品集」10 页（`examples/c-dark-portfolio.json`，由 `scripts/make_c_example.py` 生成）。
> 照片：`assets/styles/c-dark-portfolio/photos/`，10 张 Unsplash 暗调产品与空间大片（来源与许可见 `photos/CREDITS.md`）。

## 一眼认出它的五个标志
1. **挂墙式作品**：照片四周留宽边，外加 1px `#2C2A27` 细框，像画廊装裱
2. **极细水印编号**：项目编号 I / II / III 用 Didot 180-380pt、颜色几乎融进墙面（`#2C2A27`），文字可以压在上面（plan 中标 `bleed: true`）
3. **展签**：右下或标题旁一组「YEAR / MATERIAL / SIZE / CLIENT」窄体小字 + 细宋值
4. **斜体 Didot 英文大标题**：封面「Objects」150pt 斜体；章节「Index」「Process」「Chronology」斜体
5. **暖金细线**：每页底部通栏暗线 + 左端 60px 暖金短线

## 配色
| 名称 | 色值 | 用途 |
|---|---|---|
| wall | `#111110` | 画廊墙面（页面底色） |
| black | `#0A0A0A` | 满版照片页底色 |
| ivory | `#EEEAE2` | 标题 |
| soft | `#B5AFA4` | 正文、展签值 |
| muted | `#6E6960` | 展签键、栏目名 |
| rule | `#2C2A27` | 细框、细线、水印编号 |
| gold | `#C8A978` | 暖金：短线、kicker、年份（极少量） |

## 字体
| 角色 | 字体 | 用法 |
|---|---|---|
| didot-en | Didot | 编号、斜体英文标题、页码、年份 |
| serif-zh | 宋体 | 作品名（字距 8-14） |
| light-zh | 宋体 Light | 正文、展签值 |
| condensed-en | Avenir Next Condensed | 展签键、页眉、kicker |
| kai-zh | 楷体 | 自述签名 |

## 页型（样例 10 页）
| 页 | 页型 | 版式要点 |
|---|---|---|
| 1 | 封面 | 满版暗调曲面；居中斜体「Objects」+「& Spaces」+ 中文 + 作者名 |
| 2 | 自述 | 无照片；左侧水印「00」+ 宋体两行；右侧细宋长文 + 楷体签名 |
| 3 | 索引 | 斜体「Index」；四张等宽缩略 + 罗马编号 + 作品名，像胶片条 |
| 4 | 项目开篇 | 水印「I」；居中装裱作品；下方作品名；右侧展签 |
| 5 | 项目细节 | 满版作品；底部半透明黑条承托小字 |
| 6 | 分屏项目 | 左 60% 满高照片；右侧水印「II」+ 作品名 + 展签 |
| 7 | 暗光项目 | 极暗满版照片，文字只放在左下暗部，几乎没有其它元素 |
| 8 | 过程 | 斜体「Process」；三张装裱小图 + 「形 / 光 / 材」 |
| 9 | 履历 | 左侧 Didot 年份年表；右上第四个项目照片 |
| 10 | 封底 | 唯一的浅色页：上方灰度吊灯横幅，斜体「Thank you」 |

## 选图
> 搜图建议：中文 `器物 / 静物 / 暗调`；英文 `still life dark, product photography, moody`

- 商业产品/器物/空间大片，暗调或黑底拍摄，主体单一
- 亮色作品放在装裱框里，不要满版；本身就暗的照片才满版
- 至少一张极暗照片做「暗光」页，制造节奏

## 禁忌
- 不用彩色强调（暖金除外）；暖金只用在线、kicker、年份
- 一页只放一个项目；不用卡片、圆角、阴影
- 文字不压在作品主体上
