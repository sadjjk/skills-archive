# F · 人物专访式个人介绍（PROFILE INTERVIEW）

> 把个人介绍做成杂志人物专访：魏碑大字的碑刻感、楷体签名与金句、Q/A 问答体、竖排姓名、半透明毛玻璃卡片压在人像上。
> 样例：「林知夏 · 个人介绍」10 页（`examples/f-premium-texture.json`，由 `scripts/make_f_example.py` 生成）。
> 照片：`assets/styles/f-premium-texture/photos/`，10 张 Unsplash 人像、剪影与书桌静物（来源与许可见 `photos/CREDITS.md`）。

## 一眼认出它的五个标志
1. **魏碑标题**：所有中文大标题用魏碑（`wei-zh`），封面竖排姓名 96pt
2. **楷体签名与金句**：署名、年份、问答引语、印章字都用楷体（`kai-zh`），配赭石色
3. **Q / A 问答体**：96pt 斜体衬线字母「Q」赭石、「A」墨黑，问题魏碑、回答细宋，中间通栏细线
4. **毛玻璃卡片**：白色 14-16% 不透明圆角卡片 + 0.75px 白描边，压在暗调人像上（档案卡、能力卡、联系方式条）
5. **赭石印章**：寄语页 56px 赭石方块 + 楷体「知夏」

## 配色
| 名称 | 色值 | 用途 |
|---|---|---|
| paper | `#EFEAE1` | 纸张米白底 |
| ink | `#1F1B17` | 墨黑：标题 |
| soft | `#4E463D` | 正文 |
| muted | `#8C8174` | 辅助文字 |
| ochre | `#A0612F` | 赭石：Q、引号、年份、印章 |
| dark | `#1C1915` | 暗页底色 |
| cream | `#F5F0E7` | 暗页文字 |

## 字体
| 角色 | 字体 | 用法 |
|---|---|---|
| wei-zh | 魏碑 | 中文标题、竖排姓名 |
| kai-zh | 楷体 | 签名、金句、年份、引号 |
| light-zh | 宋体 Light | 正文（行距 1.9-2.0） |
| script-en / serif-en | 斜体衬线 | Q/A 字母、英文签名 |

## 选图
> 搜图建议：中文 `人像（侧脸/窗边/剪影） / 书房 / 静物`；英文 `portrait profile, silhouette, desk, stationery`

- 侧脸、窗边、剪影这类不露全脸的人像（客户提供本人照片时同理：侧光、留出暗部）
- 书桌、台灯、铅笔、笔记本等安静静物，用作窄条与时间轴配图
- 人像页文字放在压暗区或毛玻璃卡片里

## 禁忌
- 魏碑只用于标题，不用于正文；楷体不超过每页 2 处
- 不用高饱和色；毛玻璃卡片上不再叠照片
- 封面不用正面大头照
