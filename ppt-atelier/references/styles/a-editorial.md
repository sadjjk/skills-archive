# A · 人文时尚杂志（EDITORIAL MAGAZINE）

> 衬线标题 / 墨色 / 图文叙事。像翻一本人文时尚杂志：刊头大字压在黑白人像上，首字下沉、双栏正文、超大引号金句，页眉页脚是完整的杂志页面系统。
> 样例：「NOIR 墨刊 · 第 07 期｜慢阅读的复兴」10 页（`examples/a-editorial.json`，由 `scripts/make_a_example.py` 生成）。
> 照片：`assets/styles/a-editorial/photos/`，7 张 Unsplash 黑白人像与建筑（来源与许可见 `photos/CREDITS.md`）。

## 一眼认出它的五个标志
1. **Bodoni 刊头**：封面 `NOIR` 190pt、字距 40，横跨整页，压在人像头顶；中文刊名「墨 刊」粗宋小字居中
2. **首字下沉**：编者按首字 72pt 朱红粗宋，正文从右侧细宋接排
3. **巨型引号金句**：300pt 朱红 Bodoni「“」+ 54pt 粗宋两行引语 + 楷体署名
4. **杂志页面系统**：页眉左栏目名（窄体全大写）、右期号；页眉下 0.75px 通栏细线；页脚左三位页码 `008`、右刊名
5. **全部黑白摄影**：照片统一 `grayscale`，唯一的颜色是朱红

## 配色
| 名称 | 色值 | 用途 |
|---|---|---|
| paper | `#F3F0EA` | 纸白底 |
| ink | `#111111` | 标题、正文、数据页底色 |
| grey | `#6E6A63` | 图注、署名、期号 |
| rule | `#C9C3B8` | 细线 |
| red | `#B3261E` | 朱红：首字、引号、栏目编号、关键数字（全套唯一彩色） |

## 字体
| 角色 | 字体 | 用法 |
|---|---|---|
| didone-en | Bodoni 72 | 刊头、页码、大数字、罗马数字、英文斜体副标 |
| display-zh | 宋体 Black | 中文标题、首字、金句 |
| light-zh | 宋体 Light | 正文（12.5pt，行距 1.85） |

| kai-zh | 楷体 | 署名 |

| 5 | 专题跨页 | 左半满版人像 + 书脊式竖排栏目名（rotate -90）；右半标题、斜体英文、引言、署名 |

## 网格
- 左右边距 64px；页眉 y=34、细线 y=58；页脚 y=676
- 双栏正文：栏宽 250-300px、栏距 32px
- 照片占比 ≥ 40% 的页面不少于全套一半

## 选图
> 搜图建议：中文 `人像（黑白） / 建筑 / 阅读场景`；英文 `portrait black and white, architecture, reading`

- 黑白或可转黑白的人像、建筑、阅读场景；人物眼神或身体朝向文字区
- 封面人像头顶留出刊头位置（上方 1/3 平整暗部）
- 横幅照片（案例页）选水平构图强的建筑

## 禁忌
- 不用第二种强调色；朱红面积 ≤ 页面 5%
- 照片不加圆角、阴影；不用彩色照片
- 正文不用黑体；不两端对齐
