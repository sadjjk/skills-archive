# 通用设计规则

把"高级感"拆成可以执行的规则，分四类：字体层级、图片与留白、网格与节奏、检查标准。
每条规则都写成可检查的形式；改稿中发现新的有效做法，补到对应小节末尾并注明来源日期。

## 1. 字体层级

宋体主标题，黑体正文，小英文做索引。

| 层级 | 角色 | 字号（pt，16:9 / 960pt 宽） | 字距 | 说明 |
|---|---|---|---|---|
| 展示大字 | serif-zh | 60-100 | 4-13 | 封面/章节单字或短词，可拆成单字文本框做疏排（E 封面「静 养 东 方」） |
| 主标题 | serif-zh | 36-56 | 2-6 | ≤ 2 行，每行 ≤ 10 字 |
| 副标题 | sans-zh / script-zh | 18-36 | 2-7 | 与主标题差一个层级，细黑或行书点缀 |
| 英文副标 | script-en / serif-en | 15-31 | 0 | 斜体衬线，紧跟中文标题，承担"气质"而非信息 |
| 正文 | sans-zh | 12.5-21 | 0-1 | 行距 1.5-1.7，每行 ≤ 22 字，≤ 3 行 |
| 索引/眉标 | sans-en / mono | 9-12 | 1.2-3 | 全大写英文，如 `01 / ABOUT ME`、`ORIENTAL WELLNESS` |
| 页脚/页码 | sans-zh + serif-en | 9-17 | 1-1.5 | 全套统一 |

- 相邻层级字号比 ≥ 1.4；同一页最多 3 个字号层级 + 索引小字
- 中文标题不加粗，靠字号与字距建立层级；英文索引全部大写并加字距
- 一套 deck 最多 2 种中文字体 + 1 种英文字体（E 风格例外：行书只做点缀）
- 手动断行：在语义停顿处用 `\n` 断开（"把感受，\n做成可被看见的秩序"），不依赖自动换行
- 避免孤字：段落末行只剩 1 个字时，调整 `w` 或改写文字

## 2. 图片与留白

先定图位与文字安全区，再选底图。

- 先在版面上划出文字区（通常左侧 40% 或左下角），再找"文字区平整/偏暗"的图片
- 图片方向不合适时用 `image_horizontal_flip` 镜像，让主体落在文字区对侧（E 第 7、9 页）
- 文字避开亮部和复杂纹理；无法避开时加 `scrim` 遮罩（不透明度 0.3-0.6，颜色取页面底色）
- 满版图片页文字只放一个角落；分栏页图文间距 ≥ 72px
- 留白是版面的一部分：内容区占画面 ≤ 60%；封面与结尾 ≤ 40%
- 图片用 cover 方式裁切：保证主体完整，裁掉边缘
- 安全边距 40px 内不放正文；页眉页脚放在边距线上（y≈34-44 / y≈668-676，各风格见风格文档）
- 图片取景形状也是风格的一部分：A/C 直角装裱、D 拱形与圆形（`mask`）、B 方块；不跨风格借用
- 照片焦点不在中心时用 `focus`（如 `"70% 40%"`）控制裁切位置，人脸与产品主体不被裁掉

### 照片与文字区

选图和定文字位置前先测照片。用脚本 `scripts/photo_zones.py`（`python3 scripts/photo_zones.py 图.jpg`）：按 16:9 cover 裁切到 1280×720，切 5×3 网格算每格平均亮度与边缘强度，输出网格和建议。

- ● 可放浅色文字：亮度 < 70 且边缘 < 12（暗部）
- ○ 可放深色文字：亮度 > 180 且边缘 < 12（亮部）
- · 两者都不满足：加半透明色块（同色系、不透明度 0.18-0.55）、加半幅衬底、用 `background_frame` 把照片挪开空出纯色栏，或把照片缩成装裱小图

## 3. 网格与节奏

边距、细线、页码统一，深浅页面有变化。

- 左右边距按风格（A/B/C/D/F 64px，E 80px），所有页面一致；左对齐元素共用同一条 x 基线
- 页眉、页脚、页码位置全套统一（具体坐标见风格文档「网格」或样例脚本的页眉页脚函数）
- 细线 1px，颜色取 rule 色；短装饰线 48-80px，长分隔线贯穿内容区
- 版式交替：图文分栏 → 满版大图 → 卡片 → 金句，避免连续 3 页同一版式
- 深浅交替：C/E 以深为主、中间插入浅页；A/B/D/F 以浅为主、用深页或满色页做章节转折与结尾
- 对齐方式交替：左对齐为主，封面/结尾/金句可居中，配合右对齐与分屏制造节奏
- 风格标志要反复出现：每种风格文档列有「五个标志」，一套 deck 至少用到四个，且封面必须用到最强的那个
- 编号统一：章节 `01 / XXX`、页码 `NN / 总数` 或 `NN`

## 4. 检查标准

逐页看断行、对齐、文字溢出与可读性。详见 `quality-check.md`。

## 5. 风格选择原则

- 同一套 deck 只用一种风格，不混用配色与字体
- 风格由用途决定：讲故事 A/F，讲数据 B，展示作品 C，讲品牌 D，讲空间 E
- 用户给参考图但不属于 A-F → 按 `iteration.md` 新建风格，而不是硬套

## 改稿沉淀（持续追加）

- 2026-10：文本框贴身画时，行距按框高自适应（多行约 1.15），不要统一写死 1.25
- 2026-10：六套风格都用通用版式时会"看起来差不多"——识别度来自每套独有的字体、取景形状和页型，逐页设计优先于自动排版
- 2026-10：英文斜体副标与中文标题间距 ≥ 0.6 倍中文字号，否则视觉上粘连
- 2026-10：出血超大字限定在 1-2 个字符（如「Q3」「+7」「07」）。3 字符以上长串（"+0.07"、"KS+0.07"）的笔画会铺满整页、与同色标题互相遮盖——数字多就把目标值改放到右下角细体（如右下「0.36」），bleed 大字只做符号化提示
- 2026-10：bleed 大字号不是越大越好。用户反复要求"再小点"的临界点大约在 200pt 上下——超过 340pt 时 2 字符就开始喧宾夺主，超过 480pt 时即使单字符也会压住版面其它内容。先给中等值（240-280pt）让用户调
- 2026-10：页面右下角"数字+横线+说明"三件套需垂直错落，数字框底与横线间距 ≥ 20px、横线与说明间距 ≥ 18px；同色系相邻文本框 y 间距 < 12px 时视觉上会粘在一起，看起来像"叠字"
